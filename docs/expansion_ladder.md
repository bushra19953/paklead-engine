# PakLead Expansion Ladder (Bushra's strategy, stated 2026-10-15)

The system this serves is the "How to Wholesale Real Estate" book-to-system
project (WholesaleSpine), adapted for Pakistan as the PakLead Engine. The
book's own farm-area discipline, applied to data coverage:

**Be specific first: start from TOWNS. Master them. Then extend town by
town. Then go up and up — city, region, country — faster at every rung.**

## Rungs

1. **Town (DONE for the starter set, 2026-10-15)** — per-town sources on
   OLX + Zameen. Starter farm = 10 Islamabad towns (G-13, DHA Defence,
   B-17, Bahria Town, Gulberg, F-7, G-11, E-11, D-12, Top City-1) + the
   Islamabad city pages + Rawalpindi city. First town sweep: 21/21
   sources ok, +433 posts in under 2 minutes (DB 728 posts / 612 leads).
   Town pages surface fresh listings the city pages' first page misses.
2. **Extend the towns** — the full Islamabad trees are already mapped
   from the sites' own links (OLX: 41 location pages; Zameen: ~75 area
   pages) and can be switched on in batches. Then Lahore towns (DHA
   phases, Bahria, Johar Town…) and Karachi towns (DHA, Gulshan, North
   Nazimabad…) the same way: harvest the town links from each city's own
   search page, verify by parse, add sources, sweep.
3. **Up: more cities** — Rawalpindi started (OLX). Next: Faisalabad,
   Multan, Peshawar, Gujranwala, Sialkot, Hyderabad, Quetta — OLX city
   ids come from OLX's own homepage links; Zameen city ids verified by
   parse before any source goes live.
4. **Up: more categories per town** — plots, flats, commercial (Islamabad
   city-level already live), then vehicles (PakWheels/OLX motors) and
   services as the book's other lead types come online.
5. **Faster at every rung** — the politeness delays are per-source, so
   coverage multiplies intake without breaking site limits; the next
   speed rung is concurrent source fetching + batched scoring in the
   pipeline (the 2.4× clustering fix is already in).

Rule at every rung: NEVER guess a URL or id — harvest it from the site's
own pages, verify the parser extracts real local records from it, only
then add it as a live source.
